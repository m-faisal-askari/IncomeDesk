# IncomeDesk video look

Use the product's dark financial dashboard palette at portrait-video scale. Keep the black canvas nearly solid; use only a localized, soft green radial glow. The IncomeDesk green belongs on analytics, key statuses, and small accents. Keep figures large, stable, and easy to scan.

## Do
- Use the exact palette above and Inter as the closest bundled match to the app's Tailwind system sans stack.
- Reuse the provided IncomeDesk SVG logo mark.
- Keep UI panels near-black with crisp borders and a restrained emerald highlight.
- Keep all sample figures labeled as demo data.

## Do not
- Add a full-screen linear gradient, fake performance claims, or abstract finance imagery.
- Use tiny interface copy, real client data, waveform graphics, or a redesigned logo.
