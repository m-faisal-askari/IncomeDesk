# IncomeDesk Beta Launch Kit

This folder contains a practical, invite-only 30-day beta launch plan for IncomeDesk, a financial workspace for independent freelancers. The plan covers launch preparation, staged onboarding, support and feedback, success measures, and the end-of-beta decision.

## Start here

1. Set a calendar start date and name one owner for each role in the [30-day plan](30-day-beta-launch-plan.md).
2. Review the [readiness checklist](readiness-checklist.md) with engineering and product. Do not invite testers until the release gate is met.
3. Adapt the [participant kit](participant-kit.md) to the real beta URL, support channel, and current feature set.
4. Use the [feedback and operations guide](feedback-operations.md) to triage reports consistently.
5. Update the [metrics scorecard](metrics-scorecard.md) at the weekly checkpoints and on Day 30.
6. Use the [15-post IncomeDesk launch campaign](incomedesklaunch-social-posts.md) for platform-neutral captions and image briefs.

## Planning assumptions

- This is a closed beta, not a public launch. Start with a small invited group and expand only after reviewing the first cohort.
- The proposed cap is 20 invited testers in the first month. Treat that as a starting point and adjust to available support capacity.
- Dates are relative to Day 1; no calendar start date was supplied.
- Feature availability, privacy wording, support details, and any release claims must be checked against the actual beta build before sending invitations.
- Targets in the scorecard are hypotheses for this beta. Small samples are directional and should be read alongside interviews and issue reports.

## Product-specific guardrails

IncomeDesk handles sensitive financial records. Verify user data isolation, backup and recovery, financial calculations, and incident handling before inviting people. Ask testers not to submit passwords, bank login details, payment card details, or unredacted financial documents in feedback. Tax figures should be described as estimates, not filing or professional advice.
